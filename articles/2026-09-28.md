# Развитие экзоскелетов, гуманоидных роботов и новых технологий в робототехнике

В робототехнике появляются новые решения для реабилитации и массового производства гуманоидных роботов. Также отмечается применение инновационных аккумуляторов и открытие части программной платформы для разработчиков. В области мягкой робототехники представлен робот с автономным движением на основе инфракрасного света.

## 1. FDA одобрила коммерческую продажу экзоскелета Eve для пациентов с травмами спинного мозга

![FDA одобрила коммерческую продажу экзоскелета Eve для пациентов с травмами спинного мозга](<https://assets.newatlas.com/dims4/default/2775d25/2147483647/strip/true/crop/5521x2899+0+391/resize/1200x630!/quality/90/?url=https%3A%2F%2Fnewatlas-brightspot.s3.ap-southeast-2.amazonaws.com%2F6f%2Ffc%2F98366a494aca9db584558c2ed156%2F3j0a7437.png&na.image_optimisation=0>)

Французская компания Wandercraft получила разрешение от FDA на продажу экзоскелета Eve. Устройство позволяет людям с травмами спинного мозга самостоятельно стоять и выполнять бытовые действия. Одобрение подтверждает соответствие медицинским стандартам и открывает путь к применению экзоскелета.

Источник: [New Atlas Robotics](https://newatlas.com/robotics/wandercraft-eve-exoskeleton-self-balancing/)

## 2. Foxconn и Alter создают Beijing Futekang для массового производства гуманоидных роботов

Компании Foxconn и Alter объявили о создании совместного предприятия Beijing Futekang. Цель проекта — запуск платформы для серийного производства гуманоидных роботов. Это свидетельствует о намерении развивать массовое производство гуманоидных систем.

## 3. Твердотельные аккумуляторы впервые тестируют на гуманоидных роботах

Твердотельные аккумуляторы применяются в качестве испытательного стенда на гуманоидных роботах. Такой подход отличается от традиционного тестирования на электромобилях. Это отражает пересечение энергетических инноваций и развития гуманоидных роботов.

## 4. Intrinsic (Google) открывает часть платформы Intrinsic Core для разработки роботов

![Intrinsic (Google) открывает часть платформы Intrinsic Core для разработки роботов](<https://robohub.org/wp-content/uploads/2026/09/DeborahLupton-PopChips-1280x678-1-1024x542.jpg>)

Компания Intrinsic, входящая в структуру Google, открыла часть платформы Intrinsic Core. Платформа совместима с ROS и предназначена для создания сложных робототехнических приложений. Открытие направлено на поддержку экосистемы разработки роботов.

Источник: [Robohub](https://robohub.org/an-open-source-approach-to-physical-ai-from-intrinsic/)

## 5. Мягкий робот на заводной пружине прыгает, используя инфракрасный свет

![Мягкий робот на заводной пружине прыгает, используя инфракрасный свет](<https://assets.newatlas.com/dims4/default/c2a1db8/2147483647/strip/true/crop/2133x1120+0+132/resize/1200x630!/quality/90/?url=https%3A%2F%2Fnewatlas-brightspot.s3.ap-southeast-2.amazonaws.com%2Fec%2F99%2F1ecc813b4a74bb5d39ec065857ae%2Fjie-yin-jumping-ring-header-full.jpg&na.image_optimisation=0>)

Исследователи из Северокаролинского государственного университета создали мягкого робота, который прыгает бесконечно долго. Робот использует энергию инфракрасного света для подзарядки заводной пружины. Эксперимент демонстрирует новые возможности в мягкой робототехнике и энергоавтономных системах.

Источник: [New Atlas Robotics](https://newatlas.com/robotics/elastic-robot-jump-infrared-light/)
