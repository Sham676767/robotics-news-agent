# Развитие робототехники в разных сферах применения

Сегодняшние новости показывают разнообразие направлений в робототехнике: от освоения традиционных ремёсел роботами до создания инструментов для внедрения гуманоидных систем и инвестиций в производство AI-инфраструктуры. Также отмечается прогресс в технологиях понимания видео для физических AI и открытие нового центра для обучения и развёртывания сервисных гуманоидов.

## 1. Agilink обучает роботизированную руку тонкой технике шёлковой вышивки

![Agilink обучает роботизированную руку тонкой технике шёлковой вышивки](<https://assets.newatlas.com/dims4/default/b99540e/2147483647/strip/true/crop/3238x1700+91+0/resize/1200x630!/quality/90/?url=https%3A%2F%2Fnewatlas-brightspot.s3.ap-southeast-2.amazonaws.com%2F38%2F38%2Ffe81e0694fed8cd4141a9d3c83fd%2Fscreenshot-2026-10-05-at-17-38-00.png&na.image_optimisation=0>)

Компания Agilink привлекла мастера традиционной вышивки Сучжоу Фу Сянхона для обучения роботизированной руки OmniHand 3 Ultra. Робот научился разделять шёлковые нити, продевать иглу, натягивать ткань на раму и выполнять стежки. Это демонстрирует возможности робототехники в освоении сложных и деликатных ручных операций.

Источник: [New Atlas Robotics](https://newatlas.com/robotics/agilink-robot-hand-learns-silk-embroidery/)

## 2. RoboBrief публикует руководство по выбору гуманоидных роботов для внедрения

![RoboBrief публикует руководство по выбору гуманоидных роботов для внедрения](<https://robobrief.tech/blog/humanoid-robot-deployments-buyer-checklist-2026/opengraph-image?90550f5b7aa5e5f3>)

Издание RoboBrief подготовило чек-лист для покупателей гуманоидных роботов с критериями выбора, компромиссами и советами по настройке. Руководство содержит ответы на часто задаваемые вопросы. Это облегчает процесс принятия решений при внедрении гуманоидных систем.

Источник: [RoboBrief](https://robobrief.tech/blog/humanoid-robot-deployments-buyer-checklist-2026/)

## 3. TwelveLabs представляет Pegasus 1.6 с возможностями понимания видео для физических AI

Компания TwelveLabs заявляет, что модель Pegasus 1.6 способна понимать видео с первого лица. Модель поддерживает рабочие процессы, включая маркировку данных для разработчиков робототехники. Это расширяет инструментарий для создания и обучения физических AI-систем.

Источник: [The Robot Report](https://www.therobotreport.com/pegasus-1-6-brings-video-understanding-physical-ai-says-twelvelabs/)

## 4. YYForce открывает в Сингапуре центр для обучения гуманоидов и развёртывания сервисных роботов

Компания YYForce запустила новый центр в Сингапуре для развития обучения гуманоидных роботов. Центр также направлен на внедрение сервисных роботов. Это расширяет инфраструктуру для подготовки и коммерческого использования гуманоидных систем.

## 5. Teradyne инвестирует в Bright Machines для интеграции робототехники в производство AI-инфраструктуры

Teradyne и Bright Machines планируют объединить робототехнические и тестовые технологии Teradyne с производственной платформой Bright Machines. Цель — улучшить процессы производства компонентов для AI-инфраструктуры. Это отражает тенденцию к автоматизации и роботизации в высокотехнологичном производстве.

Источник: [The Robot Report](https://www.therobotreport.com/teradyne-invests-ibright-machines-brings-robotics-ai-infrastructure-manufacturing/)
