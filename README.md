# Legal Reels Agent

Python-проект для коротких вертикальных видео о юриспруденции РФ.
Целевой формат — **Instagram Reels, 9:16, 30–60 секунд**.

Доступны сбор юридических тем из RSS/HTML, дедупликация, отбор и история
использованных тем, а также типизированные настройки, клиент OpenRouter
с ретраями, проверки текста и черновики для редактора. Команда `script`
генерирует сценарий через OpenRouter и сохраняет проверенный JSON.
Озвучка через ElevenLabs и рендер вертикального MP4 доступны командами `tts`
и `render`. Публикация относится к следующим этапам.

План переноса: [docs/migration_plan.md](docs/migration_plan.md).
Допущения: [docs/decisions.md](docs/decisions.md).

## Установка и проверка

Требуется Python **3.11+**. Используйте отдельное виртуальное окружение:

```bash
python3 -m venv .venv
source .venv/bin/activate
# Windows PowerShell: .venv\Scripts\Activate.ps1
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m pip check
```

Для запуска без тестов достаточно `requirements.txt`.

```bash
python -m app
# Равнозначная точка входа:
python main.py
```

Без аргументов проверяется конфигурация и выводится статус основы проекта.
Сеть и API-ключи для этого не нужны, файлы не создаются.

## Локальный черновик

Вход — JSON с полями `draft` и `sources`. Технический пример:
[tests/fixtures/legal_draft.json](tests/fixtures/legal_draft.json).
Он содержит только учебный текст, без норм права и юридических рекомендаций.

```bash
python -m app --draft tests/fixtures/legal_draft.json
```

После успешной проверки в `drafts/` появляется отдельный
`legal-draft-<uuid>.json`. Повторные запуски не затирают предыдущие черновики.
Пакет содержит исходные материалы, ссылки на источник каждого блока и статус
`review_required`. Сохранение не означает юридическую проверку или готовность
к публикации. Сохранённый пакет можно повторно передать через `--draft`.

Контракт текущего этапа:

- `draft.title`, `draft.intro` — непустой русский текст;
- `draft.sections` — непустой массив объектов `headline`, `body`, `source_index`;
- `sources` — непустой массив объектов `title`, `source`, `url`, `content`,
  `jurisdiction`; юрисдикция — `RU`, URL — HTTP(S);
- `source_index` начинается с **1** и ссылается на элемент `sources`;
- ссылки берутся из входных материалов, текст блока не задаёт собственный URL;
- количество материалов и блоков не привязано к пяти; несколько блоков могут
  использовать один источник.

Проверки обнаруживают пустые поля, неверную привязку, преобладание английского
текста, некоторые рекламные усиления и числа, которых нет в соответствующем
источнике. **Они не подтверждают существование и актуальность нормы, правильность
её толкования или применимость к конкретной ситуации.** Это должен проверять
редактор по первоисточнику. Источники сбора и домены первоисточников заданы в `sources.yaml`.

## Настройки

Все поддерживаемые переменные перечислены в [.env.example](.env.example):

| Переменная | Назначение |
| --- | --- |
| `APP_ENV`, `LOG_LEVEL` | Окружение и уровень логов |
| `DRAFTS_DIR` | Папка черновиков, по умолчанию `drafts` |
| `SCRIPT_CTA` | Финальная фраза озвучки: «Сохраните ролик и поделитесь им» |
| `TTS_PROVIDER`, `TTS_OUTPUT_DIR` | Провайдер озвучки и папка аудио; по умолчанию `elevenlabs`, `audio` |
| `ELEVENLABS_API_KEY`, `ELEVENLABS_VOICE_ID` | Ключ ElevenLabs и выбранный голос, задаются в `.env` для Compose |
| `ELEVENLABS_MODEL_ID` | Модель озвучки; по умолчанию `eleven_multilingual_v2` |
| `TTS_TIMEOUT`, `TTS_MAX_ATTEMPTS`, `TTS_RETRY_BASE_SECONDS`, `TTS_RETRY_MAX_SECONDS` | Таймаут и ограниченные повторы TTS |
| `OPENROUTER_API_KEY` | Ключ для `collect` и `script` |
| `OPENROUTER_MODEL`, `OPENROUTER_FALLBACK_MODELS` | Основная модель и необязательные запасные модели |
| `OPENROUTER_TIMEOUT`, `OPENROUTER_MAX_ATTEMPTS` | Таймаут и максимальное число запросов |
| `OPENROUTER_RETRY_BASE_SECONDS`, `OPENROUTER_RETRY_MAX_SECONDS` | Задержки между повторными запросами |

Python CLI **не загружает `.env` автоматически**. Локально задавайте переменные
окружения через оболочку, например `export DRAFTS_DIR=./drafts`.
Команды `collect` и `script` используют `app.openrouter_client.request_json`.
Для них нужен `OPENROUTER_API_KEY`; запуск без аргументов и
проверка локального черновика по-прежнему работают без ключа. Модель оставлена из прежнего
редактора; это не результат сравнения моделей для юридических сценариев.

Ключи не должны попадать в Git, сообщения об ошибках или логи.
`.env` и выходные черновики исключены из Git.

## Структура

```text
app/
  cli.py                — единая точка запуска
  config.py             — проверяемые настройки окружения
  models.py             — LegalSource, LegalSection, LegalDraft
  openrouter_client.py  — JSON, таймауты и ограниченные ретраи
  draft_validation.py   — общая проверка черновика и источников
  fact_guard.py         — ограниченная проверка числовых добавлений
  language_guard.py     — проверка русского текста
  legal_draft.py        — чтение и сохранение пакета для редактора
  reel_script.py        — типы, JSON-схема и проверка сценария
  script_generator.py   — выбранная тема → OpenRouter → отдельный JSON
  script_review.py      — отдельная LLM-сверка и причины отказа
  legal_references.py   — извлечение явных реквизитов без додумывания
  tts.py                — интерфейс TTSProvider, типы и оценочные тайминги
  elevenlabs_tts.py     — ElevenLabs: посимвольные метки → слова, PCM → WAV
  tts_factory.py        — выбор реализации через конфиг
  tts_pipeline.py       — проверка и сохранение аудио с таймингами
```

Тесты запрещают реальные сетевые обращения и используют моки для OpenRouter.
GitHub Actions остаётся на паузе; единственный шаблон тестов хранится как
`.github/workflows/tests.yml.disabled`.

## Контейнер

```bash
cp .env.example .env
docker compose build
docker compose run --rm agent
# Проверить технический пример, включённый в образ:
docker compose run --rm agent python -m app --draft tests/fixtures/legal_draft.json
```

Compose передаёт `.env` через `env_file` и сохраняет черновики в `./drafts`.
Каталог `./data` тоже подключён к контейнеру и хранит подборку и историю тем.


## Сбор тем

Целевая аудитория — предприниматели и люди с потенциальной потребностью
в юридической помощи. По умолчанию отбирается **1 тема на ролик** за последние
**30 дней**. Настройки и стартовый список — в `sources.yaml`.

```bash
# Перед collect задайте OPENROUTER_API_KEY через окружение.
python -m app collect
python -m app collect --count 2 --max-age-days 30
# После фактического использования темы (id печатает collect):
python -m app mark-used topic-ИДЕНТИФИКАТОР
```

Одинаковые URL и явные повторы объединяются локально, смысловые повторы —
через OpenRouter. Все источники сохраняются. Подборка находится в
`data/collected_topics.json`, история — в `data/topic_history.sqlite3`.
Сбор сам по себе не помечает тему использованной. При недостатке подходящих
тем выводится неполная подборка с кодом выхода 3.

Сейчас часть официальных сайтов недоступна из среды проверки; ошибки
попадают в отчёт, TLS-проверка остаётся включённой. Отбор требует доступного
прямого первоисточника с извлечёнными реквизитами. Источники и подробные
правила: [docs/collection.md](docs/collection.md).

## Сценарий

После `collect` создайте сценарий одной выбранной темы:

```bash
python -m app script
# Для другой подборки и нового выходного файла:
python -m app script --input data/collected_topics.json --output drafts/my-script.json
# Если collect отобрал несколько тем, укажите ровно одну:
python -m app script --topic-id topic-ИДЕНТИФИКАТОР
# В контейнере после настройки ключа в .env:
docker compose run --rm agent python -m app script
```

Модель берётся из `OPENROUTER_MODEL`. В стандартный вывод попадает только JSON:
`hook`, `voiceover`, `on_screen_text[]`, `caption`, `hashtags[]`, `sources[]`,
`disclaimer`. Тот же объект сохраняется в новый `drafts/reel-script-<uuid>.json`
или в `--output`; существующие файлы не заменяются. Сообщения идут в stderr.

`voiceover` содержит **всю озвучку на 80–140 слов**: четыре абзаца с хуком,
сутью, действиями зрителя и CTA. Хук ограничен восемью словами как приближение
трёх секунд; точный хронометраж определяется готовой озвучкой.
`sources[]` содержит карточки `title`, `url`, `citation`, `law`, `article`, `part`.
Нужна хотя бы одна конкретная норма из текста первоисточника с законом и статьёй;
часть указывается при наличии, без выдумывания номера. У новости реквизиты
могут быть пустыми, первоисточник приведён отдельно. Обязательный дисклеймер —
**«Не является юридической консультацией»**.

Лимиты: озвучка 80–140 слов, до 6 титров одной строкой по 60 символов,
подпись до 1000 символов, 1–10 уникальных хэштегов. Категоричные обещания
вроде «вам точно положено» без оговорки в том же предложении блокируются.

После генерации отдельный запрос к модели сверяет каждое утверждение с
сохранённым текстом первоисточника. Подтверждения требуют URL и дословной цитаты.
При расхождении, нехватке данных или сбое сверки сценарий сохраняется с причинами
в `drafts/quarantine/`, stdout остаётся пустым, код выхода — **3**. Путь `--output`
при этом не создаётся. Локальную блокировку нельзя отменить одобрением LLM.

Невалидные JSON, схема, длина, структура и подменённые источники вызывают
повтор в лимите `OPENROUTER_MAX_ATTEMPTS` для каждого этапа: генерация и сверка.
Если генерация не удалась, код выхода 2, нового сценария нет. Если не удалась
сверка уже полученного сценария, он сохраняется в карантин с кодом 3.
Успешный сценарий сопровождается `*.review.json` с результатами, снимком
источников и контрольными суммами. После изменения данных нужна новая сверка.
Правовую редактуру проверки не заменяют; разрешение автоматической публикации
не выдаётся. Старые подборки без текста первоисточника нужно собрать заново.
Тема останется неиспользованной до отдельной команды `mark-used`.
Подробности: [docs/script.md](docs/script.md).

## Озвучка и тайминги слов

В `.env` задайте `ELEVENLABS_API_KEY` и `ELEVENLABS_VOICE_ID` своего голоса.
`TTS_PROVIDER=elevenlabs` выбирает первую реализацию общего `TTSProvider`.

```bash
docker compose build
docker compose run --rm agent python -m app tts --input drafts/reel-script-ID.json
# Локально — с переменными окружения, Python сам .env не читает:
python -m app tts --input drafts/reel-script-ID.json
python -m app tts --input drafts/reel-script-ID.json --output-dir audio/preview
```

Вход — успешный сценарий и соседний `.review.json`. Изменённый или заблокированный
сценарий отклоняется до запроса TTS. Озвучивается только весь `voiceover`, один раз;
хук и CTA повторно не добавляются. Правовая публикация и подтверждение использования
темы не выполняются.

Результат каждого запуска — новая папка `audio/tts-<uuid>/` с `audio.wav` и
`timings.json`. В JSON для каждого слова есть `word`, `start`, `end` в секундах.
Основной вариант — тайминги ElevenLabs (`timing_source: provider`). Если их нет
или они относятся к другому тексту, используются явно помеченные оценочные
тайминги (`estimated`) по длине фраз и фактической длительности WAV.
Повреждённые тайминги не выдаются за корректные. Аудио подключено к контейнеру
как `./audio:/app/audio` и исключено из Git.

Новые провайдеры добавляются отдельным адаптером и записью в фабрике без
изменения пайплайна. Вторая реализация пока не добавлялась.
Формат, ограничения и инструкция: [docs/tts.md](docs/tts.md).

## Рендер видео

```bash
docker compose build
docker compose run --rm agent python -m app render \
  --input drafts/reel-script-ID.json --timings audio/tts-ID/timings.json
# Фоновые клипы вместо градиента:
docker compose run --rm agent python -m app render \
  --input drafts/reel-script-ID.json --timings audio/tts-ID/timings.json \
  --clips-dir backgrounds --template templates/default.yaml
```

Выход — новый `renders/render-<uuid>/video.mp4`, H.264/AAC, 1080×1920, до
90 секунд вместе с финальным экраном. В кадре: крупные синхронные субтитры,
плашки с конкретными нормами и полными URL, обязательный дисклеймер.
Результат автоматически проверяется через ffprobe. Изменённые сценарий или
аудио и слишком длинная озвучка отклоняются. Публикация не выполняется.

Название услуги и контакт оставлены **настраиваемыми**: заполните
`service_name` и `contact` в `templates/default.yaml`. Пока поля пусты,
финал показывает CTA и дисклеймер. Шаблоны, фоновые клипы, полный пример
запуска и проверок: [docs/render.md](docs/render.md).
