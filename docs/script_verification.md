## Ограничения и ручная проверка

Локальный `.env` не содержит настроенного ключа OpenRouter. Платный запрос
к реальной модели и качество её ответа в этом этапе не проверены. Прежде чем
пользоваться результатом, нужно задать ключ в окружении (или `.env` для Compose),
выполнить `collect`, затем `script` и оценить реальный сценарий.

Редактору нужно сверить правовые выводы, номера, актуальность и условия применения
с полными первоисточниками. Проверки кода этого не доказывают. Доступность ссылок
наследуется из снимка сбора; она не проверяется повторно генератором.

Хук до восьми слов — приближение трёх секунд. Точную длительность хука и ролика
нужно измерить при озвучке. Также вручную оцениваются простой язык, практическая
польза для предпринимателей и потенциальных клиентов юриста, титры, подпись и CTA.

Генерация не подтверждает использование темы. Команда `mark-used` остаётся
отдельным действием после фактического использования. Подробные команды —
в `docs/script.md`.
