# План миграции в Legal Reels Agent

Исходная точка: `main`, коммит `f29774fe01e3be9a67278653598d1ef702711a20`.
До изменений: 108 тестов проходят. Исследованы основной запуск, все модули
`app/`, тесты, настройки, контейнер и отключённые workflows.

Цель проекта — короткие вертикальные видео о юриспруденции РФ:
Instagram Reels, 9:16, 30–60 секунд. **Этот этап — только очистка и выделение
переиспользуемой основы.** Генерация сценария, поиск юридических материалов,
озвучка, субтитры, рендер и публикация в этом этапе не реализуются.

## Что сохраняется

| Возможность | Исходный код | Результат этапа |
| --- | --- | --- |
| OpenRouter: таймаут, ограниченные ретраи, Retry-After, разбор JSON | `article_editor.py` | Отдельный `app/openrouter_client.py`, без редакционной тематики и сетевых вызовов при импорте |
| Настройки через окружение, секреты вне Git | `.env.example`, разрозненные `os.getenv` | Типизированный `app/config.py`, обновлённый `.env.example` |
| Черновик для ручной проверки | `vk_draft.py`, запись Markdown в редакторе | `app/legal_draft.py`: локальный JSON со статусом `review_required` и исходными материалами; нет SDK социальной сети |
| Структурные проверки и привязка к источнику | `validate_article`, `_attach_sources` | `app/draft_validation.py`, ссылки берутся только из входных материалов |
| Проверка числовых добавлений и рекламных усилений | `fact_guard.py` | Общая проверка для юридического черновика; это НЕ проверка действительности нормы права |
| Проверка русского языка | `language_guard.py` | Та же проверка без требований к ежедневному дайджесту |
| Логирование и тестируемость | сборщик и тесты | `logging`, тесты без реальных внешних API |
| Запуск из Python и контейнера | `main.py`, `app/__main__.py`, Docker | Одинаковые точки входа; без параметров — проверка конфигурации, с `--draft` — проверка и сохранение предоставленного черновика |

## Что удаляется

- `app/vk_publisher.py`, `vk_media.py`, `vk_image_smoke_test.py`: API стены,
  токены, загрузка фотографий, ID публикаций и все параметры `VK_*`.
  `vk_draft.py` заменяется независимым хранилищем черновиков.
- `collector.py`, `relevance.py`, `ranking.py`, `daily_selection.py`, старый
  `ai_client.py`, `ai_smoke_test.py`: RSS-сбор робототехники, словари,
  эвристики, веса источников, TOP-5 и запасной ранжировщик. Новые юридические
  источники и правила отбора нельзя получить переименованием старых.
- `article_editor.py`, `fallback_article.py`: промпты и схемы ежедневного
  выпуска; универсальные проверки и транспорт OpenRouter выделяются отдельно.
  Автоматический запасной текст не переносится в юридическую тематику.
- `image_fetcher.py`, `image_fetcher_v2.py`, `preview.py`,
  `preview_images_v2.py`, `article_preview.py`: поиск изображений к новостям
  и страницы предпросмотра старого дайджеста. Медиа для видео будут отдельным
  модулем; права на материалы требуют отдельного решения.
- `database.py`: SQLite-схема `news_items` и дедупликация по заголовкам новостей.
  JSON-черновики остаются; юридическое хранилище не создаётся заранее.
- `gigachat_client.py`: неиспользуемый вторичный провайдер и его отдельные
  настройки. Текущий проект сохраняет OpenRouter.
- `config/sources.yaml`, `articles/`, `data/latest_top5*.json`: источники и
  сгенерированные материалы старой тематики. Они доступны в истории Git.
- Старые workflows публикации/изображений/сбора, оба набора systemd-служб и
  таймеров, служебная HTML-страница: ежедневное расписание больше не соответствует
  проекту. Новое развёртывание и расписание решаются позднее.
- Тесты удалённых интеграций и эвристик. Общие проверки чисел, языка, ретраев,
  черновиков и точек входа сохраняются либо переносятся на новый контракт.

Прямые зависимости после очистки: только `httpx`; тесты — `pytest`.
`feedparser`, `PyYAML`, `python-dateutil` удаляются вместе с RSS-конвейером;
`Pillow` — вместе с загрузкой картинок; `tzdata` — вместе с расписанием.
Это зависимости удаляемых возможностей, специализированного Python-пакета VK
в исходнике не было: API вызывался через `httpx`.

## Приёмка текущего этапа

- Новая установка из `requirements-dev.txt`, все тесты, проверка зависимостей.
- Оба запуска `python main.py` и `python -m app` работают без ключей и сети.
- Некорректный черновик не сохраняется; корректный получает статус
  `review_required`, исходные материалы и ссылки.
- Сетевые вызовы в тестах запрещены по умолчанию; клиент тестируется моками.
- В рабочем коде и окружении нет API/токенов VK, словарей робототехники,
  отбора пяти новостей и старых автопубликаций.
- Вручную: прочитать README и решения, проверить пути/переменные окружения,
  открыть сохранённый JSON и проверить привязку к источникам. Юридическую
  достоверность подтверждать отдельно; автоматические проверки её не гарантируют.
