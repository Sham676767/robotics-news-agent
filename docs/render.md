# Рендер вертикального ролика

Команда работает локально после сверки сценария: `script.json` и соседний
`.review.json`, `audio.wav` + `timings.json`. Хеши связывают текст, источники,
проверку и озвучку. Результат остаётся на ручном одобрении.

```bash
python -m app render --input drafts/reel-script-ID.json \
  --timings audio/tts-ID/timings.json --template templates/default.yaml
# Своя локальная библиотека:
python -m app render --input drafts/reel-script-ID.json \
  --timings audio/tts-ID/timings.json --clips-dir backgrounds
# Без ключей и внешних запросов, реальный MP4:
python -m app run-all --stub
```

В Docker добавьте `docker compose run --rm agent` перед `python`.
Требуются FFmpeg/libx264/libass, ffprobe и зависимости requirements.txt.
DejaVu Sans Bold включён с лицензией; другой шрифт должен быть установлен
и доступен Fontconfig. Pillow измеряет текст тем же файлом шрифта.

## Изображение и титры

- MP4 H.264/yuv420p, AAC 48 кГц, 1080×1920, 30 FPS, faststart.
- Длительность **30–45 секунд после удаления тишины**. Короткий/длинный текст
  нужно переозвучить; речь не ускоряется, словесный хвост не обрезается.
- VISUALS_DIR по умолчанию assets/visuals. Принимаются 1–20 PNG/JPEG/WebP
  или MP4/MOV/MKV/WebM. Можно смешивать. Используется центральный кроп 9:16;
  каждый план ≤3,5 секунды, приближение/отдаление и короткий fade на стыке.
  Свой звук клипов игнорируется, материалы из сети не скачиваются.
- Хук крупно целиком первые 3 секунды, с движением/масштабом и коротким звуковым акцентом.
- Затем группы 2–5 слов из озвучки, по таймингам слов. Границы учитывают
  пунктуацию, паузы и служебные слова; предлог/союз не остаётся последним
  на экране или строке. Длинные неразбиваемые фразы отклоняются.
- Шрифт титров ≥60 px, до трёх строк (третья позволяет сохранить длинную смысловую группу), ширина измеряется с запасом под анимацию.
  Акцентные слова подсвечены, цифры/суммы из речи дополнительно выделяются крупно.
- Рабочая зона текста x=90..930, y=250..1520: верхние 250 и нижние 400 px свободны,
  справа остаётся место кнопкам. Под текстом контрастная подложка; ASS-клип
  дополнительно ограничивает каждый слой. Фон может заполнять весь кадр.
- `header_text`, цвета и шрифт — templates/default.yaml; имя — EXPERT_NAME,
  логотип — BRAND_LOGO (локальный PNG/JPEG). Название `service_name` читается
  из старых шаблонов как запасное. Контакт берётся из CTA_CONTACT в .env.
- Мини-шаблоны templates/formats: вопрос-ответ, три ошибки, было/стало, чек-лист.
  Сценарий выбирает формат, плашки шагов следуют предложениям, а не смене фона.
- Короткая норма видна только у произнесённого номера статьи, до 3 секунд.
  URL остаются в подписи. Дисклеймер — последние 1,6 секунды и подпись.
- CTA появляется во время завершающей речи в последних 8 секундах. Отдельной
  тихой заставки нет. Устаревший end_seconds читается, но новый рендер его не добавляет.

## Звук и лицензия

Исходный WAV и метки сохраняются. По RMS (−45 dBFS, окна 10 мс) удаляются только
тихие участки: оставляем до 80 мс в начале, 150 мс в конце и 280 мс между фразами.
Все тайминги пересчитываются по карте вырезов. Полностью тихий WAV отклоняется.
Точность провайдерских меток сохраняет значение; estimated не становится provider.

Речь нормализуется к −16 LUFS, музыка приглушается sidechain-компрессором
при речи, пик ограничивается. Музыка — из локального MUSIC_MANIFEST:

```yaml
file: calm-loop.wav
license: CC0-1.0
commercial_use: true
source: 'Происхождение трека и подтверждение прав'
attribution: ''
```

Разрешены CC0-1.0, CC-BY-4.0, original, licensed. Для CC-BY обязательна
атрибуция; она добавляется в подпись. Это проверка декларации владельца,
не экспертиза чужого договора. Встроенный трек создан без чужих семплов,
воспроизводится tools/build_music.py. Пустой MUSIC_MANIFEST отключает музыку.

## Результаты и обложка

Каждый запуск создаёт новую папку render-ID:

- video.mp4, subtitles.ass, render.json;
- narration.wav — обработанная озвучка;
- cover.jpg — реальный кадр хука;
- contact-sheet.jpg — смены визуала с временами для ручной проверки;
- storyboard.json — планы и текстовые слои с границами и временами.

COVER_FRAME_SECONDS=1, допустимо 0,3–2,7 с внутри хука. При публикации этот
же кадр выбирается через thumb_offset (миллисекунды); JPEG доступен для ручной
загрузки/других площадок. Изменение настройки требует нового рендера и одобрения.

render.json хранит тему, формат, варианты хуков и индекс выбора, CTA, длительность,
кадры, карту аудиовырезов, лицензию/ducking и контрольные суммы. Дата публикации
до отправки null; подтверждённая дата хранится в state.json.publication_date,
чтобы не переписывать одобренный файл и не ломать его хеш. Команда stats соединяет их.
Новые артефакты включаются в контрольные суммы пакета; старые версии читаются отдельно.

Перед approve просмотрите ролик со звуком на телефоне, обложку и контактный лист;
проверьте применимость нормы, хук, синхронизацию и читаемость. Stub использует
вымышленные реквизиты и тон: он проверяет технику/оформление, не заменяет просмотр
настоящей озвучки. Публикация stub-пакета запрещена.
