# Локальная библиотека

01-desk.png — самостоятельная иллюстрация, ранее созданная встроенным image_gen
для этого проекта. Чужие кадры Instagram не используются.
02–04 — оригинальные геометрические иллюстрации tools/build_visuals.py, CC0.
Рендер циклически меняет изображения не реже чем раз в 3,5 секунды,
чередует приближение и отдаление. Можно указать свою папку VISUALS_DIR
или --clips-dir с PNG/JPEG и/или MP4/MOV/MKV/WebM. Звук клипов игнорируется.
Права на добавленные пользователем материалы проверяет владелец библиотеки.
