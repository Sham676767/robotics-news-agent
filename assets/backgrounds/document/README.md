# Кабинет юриста

Шесть оригинальных изображений, OpenRouter/openai/gpt-image-2, 02.11.2026.
Источник: подтверждённый запуск GitHub Actions 41479816888 в этом проекте.
Они не взяты из референса Instagram. На книгах нет читаемых надписей и брендов.
`library.json` задаёт шесть JPEG для ротации. Рядом сохранены JSON с промптами,
моделью, датой, SHA-256 экспорта и оригинала, масками fire_box/light_box.

Оригинальные PNG 1152x2048 остаются локальным кэшем команды generate-backgrounds
и в артефакте GitHub; в Git включены JPEG такого же разрешения. Экспорт не
создаёт нового платного запроса. Не удаляйте PNG-кэш, если повторяете генерацию.
Координаты масок можно поправить после ручного просмотра отдельного фона.
